# פיצת יום הבוחר — גרסת HTML מלאה

## מה כלול

- `index.html` — אתר ההזמנה המלא. העיצוב, התמונות והקוד מוטמעים בתוך הקובץ, ללא React וללא צורך בבנייה.
- `admin.html` — מסך ניהול: כל ההזמנות, חיפוש לפי שם, סיכום כמויות, פירוט תוספות, ייצוא אקסל ומחיקה.
- `worker.mjs` — רכיב שרת לשמירת הזמנות ולהגנה על הגישה לניהול.
- `schema.sql` — מסד נתונים להזמנות ולמניעת ניסיונות סיסמה חוזרים.
- `wrangler.jsonc` — הגדרת פרסום ב־Cloudflare Workers.
- `worker.test.mjs` — בדיקות אוטומטיות.

## פתיחה מהמחשב

לחיצה כפולה על `index.html` מציגה את כל העיצוב והאפשרויות, כולל תמונת הפרגוד, ששת פתקי התוספות, הפיצה החיה והצפה, תשעת סוגי השתייה ותפוח האדמה המוקרם.
בפתיחה מקומית ניתן לנסות את בחירת המוצרים; סיום הזמנה מציג הודעה שנדרש שרת. לא מוצג אישור הזמנה כוזב.

## העלאה ל־GitHub

כל הקבצים נמצאים ברמה אחת, ואין צורך להעלות תיקיות או לחלץ ZIP באתר GitHub. מעלים את הקבצים עצמם, לרבות `index.html`.
GitHub Pages יכול להציג את ממשק ההזמנה, אך אינו מפעיל את `worker.mjs` או את מסד הנתונים. להצגה בלבד ניתן לפרסם Pages; להפעלת הזמנות וניהול יש לפרסם את החבילה ב־Cloudflare Workers.

## הפעלה מלאה ב־Cloudflare Workers

1. יוצרים מסד D1 ומעתיקים את מזהה המסד ל־`database_id` בתוך `wrangler.jsonc`.
2. מפעילים במסד את התוכן של `schema.sql` פעם אחת.
3. מגדירים את הסודות `ADMIN_PASSWORD`, `ADMIN_SESSION_SECRET` ו־`ADMIN_EMAIL` בצד השרת בלבד. יש להשתמש במפתח אקראי ארוך ל־`ADMIN_SESSION_SECRET`. הסיסמה הקיימת לא כתובה בקוד; יש להזין אותה כסוד בשרת החדש.
4. כדי לשמור גם על הגבלת הניהול לחשבון שלך, מגדירים Cloudflare Access לאזור הניהול ומאפשרים את כתובת האימייל שלך בלבד. מגדירים בשרת `ACCESS_TEAM_DOMAIN` ו־`ACCESS_AUD` בהתאם לאפליקציית Access. מומלץ להגן על נתיבי `/admin`, `/admin.html`, `/manage` ו־`/api/admin/*` באותה אפליקציה. השרת מאמת את חתימת JWT, המנפיק, הקהל, התוקף והאימייל, ואינו מסתמך על כותרת אימייל בלבד.
5. משאירים `ADMIN_IDENTITY_MODE=access`. מצב `sites` מיועד רק לאירוח מאחורי מנגנון הזיהוי האמין של Sites, ואסור להשתמש בו ב־Worker ציבורי רגיל.
6. מתקינים את כלי הפרסום: `npm install`.
7. מריצים בדיקות: `npm test`.
8. מפרסמים: `npm run deploy`.

אין שלב build. כתובת האתר מתקבלת משירות האירוח. הגישה להזמנות ניהוליות נחסמת עד שהוגדרו הזיהוי והסודות.

## פרטיות ונתונים

הסיסמה אינה נשלחת לקוד הדפדפן. הניהול דורש חשבון מורשה וסיסמה; ההרשאה נשמרת בעוגייה חתומה מסוג HttpOnly/Secure למשך שמונה שעות. לחיצה על נעילת אזור הניהול מסירה אותה.
הזמנות חדשות נשמרות במסד מרכזי. הורדה או העתקה של קובצי HTML אינה חושפת הזמנות של אחרים.
החבילה כוללת את תכונות האתר והעיצוב, אך לא מעתיקה אוטומטית הזמנות ממסד האתר המקורי. מסד חדש מתחיל ריק. האתר המקורי נשאר ללא שינוי.
